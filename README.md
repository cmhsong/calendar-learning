# 달력 배우기

하루 → 일주일 → 한 달 → 1년 → 달력 보기 순서로 배우는 쉬운 웹 학습지입니다.

- 상단 메뉴에서 단원을 고르고, 「배워요」 → 「풀어요」 순서로 공부합니다.
- 달을 누르면 그 달 달력이 나오는 「달력 넘겨 보기」
- 문제는 풀 때마다 무작위로 바뀝니다.
- 「학습지 만들기」: A4 모양 그대로 미리 보고 인쇄합니다. ‘새 문제로 바꾸기’를 누를 때마다 문제가 바뀌고, 학습지 번호가 같은 정답지를 함께 뽑을 수 있습니다.
- 글자 크기 · 화면 비율 조절, 정답 칭찬 소리와 축하 효과
- 연도를 눌러 작년·올해·내년 이후 달력을 볼 수 있고, 해가 바뀌면 올해 기준이 자동으로 바뀝니다.
- 주소 뒤에 `?date=2026-10-05` 를 붙이면 그 날짜를 '오늘'로 삼습니다.

## 사용한 오픈 소스
- [canvas-confetti](https://github.com/catdad/canvas-confetti) (ISC)
- [Pretendard](https://github.com/orioncactus/pretendard) (SIL OFL)
- [holidays-kr](https://github.com/hyunbinseo/holidays-kr) 공휴일 API (키 없이 무료, 달력의 빨간 날 표시)
